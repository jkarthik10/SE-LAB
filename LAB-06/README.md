# L6_L7_59 — Phone Repair Quote
## Lab 6: Code and Branch Coverage Analysis

### Application
`phone_repair_quote.py` provides repair quotes, repair-time estimates, and phone trade-in values.

### Lab 6 deliverables
- `CodeCoverageTest_phone_repair_quote_application.py` — tests for statement/line coverage.
- `BranchCoverageTest_phone_repair_quote_application.py` — tests for decision/branch coverage.
- `coverage_code.txt` and `coverage_branch.txt` — text reports generated by the commands below.
- `screenshots/` — save terminal screenshots showing each successful report here.

### Setup (Windows PowerShell)
```powershell
cd LAB6
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

### Code coverage
```powershell
coverage erase
coverage run --source=phone_repair_quote -m pytest CodeCoverageTest_phone_repair_quote_application.py
coverage report -m
coverage report -m > coverage_code.txt
```

### Branch coverage
```powershell
coverage erase
coverage run --branch --source=phone_repair_quote -m pytest BranchCoverageTest_phone_repair_quote_application.py
coverage report -m
coverage report -m > coverage_branch.txt
```

The report should show the `phone_repair_quote.py` row at or above 90%. The branch command reports branch coverage as well as statement coverage. Take screenshots of the terminal output after each run and save them in `screenshots/`.

### Required separate commits
Run these from the repository root after adding the files:
```powershell
git add LAB6/CodeCoverageTest_phone_repair_quote_application.py LAB6/coverage_code.txt
git add LAB6/screenshots/code-coverage.png
git commit -m "Add phone repair quote code coverage tests"
```
Then, after running branch coverage and saving its screenshot:
```powershell
git add LAB6/BranchCoverageTest_phone_repair_quote_application.py LAB6/coverage_branch.txt
git add LAB6/screenshots/branch-coverage.png
git commit -m "Add phone repair quote branch coverage tests"
git push
```

If you use a different screenshot filename, update the `git add` path accordingly.
